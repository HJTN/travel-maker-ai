# 기능 명세

## MVP 핵심 기능

### 1. 이미지 기반 개인 취향 분석 (S03, S04)
- 여러 사진 중 마음에 드는 이미지를 고르는 방식으로 취향 테스트를 진행한다.
- 음식, 여행, 문화생활, 여가 활동 등 카테고리별로 분석한다.
- 결과를 키워드와 유형으로 분류해 시각화한다.

### 2. 동행자 간 취향 매칭 및 비교 (S06, S07, S08)
- 초대 ID나 링크로 동행자와 연결하고, 각자의 취향 분석 결과를 공유한다.
- 취향 일치도와 공통 관심사를 시각적으로 보여준다.
- 선호하는 활동과 선호하지 않는 활동을 비교해 취향 차이를 쉽게 파악하게 한다.

### 3. AI 기반 갈등 예방 및 취향 조율
- 선호도 차이가 큰 항목을 찾아 의견 충돌 가능성이 있는 영역을 파악한다.
- 한 사람에게 치우치지 않는 절충안을 제시한다.
- AI가 **추천 이유를 설명**한다.

### 4. 공통 취향 기반 맞춤형 일정 생성 (S10)
- 공통 관심사와 개별 선호도를 종합해 활동을 추천한다.
- 음식점, 카페, 여행지, 놀거리 등 상황에 맞는 선택지를 제공한다.
- 인기순이 아니라 **동행자 모두의 예상 만족도**를 기준으로 추천한다.
- 일정은 공통 / 분리 / 번갈아 세 유형으로 구성한다.

### 5. 취향 프로필 저장 및 업데이트
- 취향 분석 결과를 프로필로 저장한다.
- 동행자와의 비교 결과와 공통 관심사를 다시 확인할 수 있다.
- 새로운 경험이나 피드백을 반영해 취향 정보를 계속 업데이트한다.

## 부차적 기능

### 여행 스탬프 기록 (S15)
- 여행 중 장소에 방문하면 스탬프를 모아 계획 완주율을 높인다.

### 커뮤니티 (S16, S17 · 후순위)
- 다른 사용자와 일정 공유
- 다른 사용자를 친구로 추가
- 다른 사용자를 다음 여행 동행자로 초대

## AI 활용 계획
- 사용자와 동행자의 취향을 모두 고려해 장소를 탐색하고 일정을 생성한다.
- 사용자별 취향 정보를 VectorDB에 저장한다 (MVP 이후. 현재 AI 서버는 Stateless이며 저장은 BE가 맡는다).
- 참여자들의 취향 정보를 연결해 LangChain 기반 여행 타임라인을 만든다.
